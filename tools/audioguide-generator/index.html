This tool allows to generate an audio version of a Guided Tour thanks to a Text-to-Speech system. For each step of the tour a .wav file is generated in the download directory of your browser. An updated version of the JSON is also returned with "lang" and "music_level" attributes added to the root of the JSON and an "audiofile" attribute added to each step of the tour.

HowTo:
  1/ Paste the JSON of the Guided Tour.
  2/ Define the parameters of the generation:
      - language,
      - speaker model,
      - relative volume level of background music (volume level of voice is 1),
      - base URL used to build the URLs of audio files that will appear in JSON).
  3/ Click the "GENERATE AUDIO FILES" button.
